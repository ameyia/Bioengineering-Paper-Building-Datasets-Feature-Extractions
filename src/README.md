# Source code

Project-authored code is grouped by responsibility:

- `data/`: dataset construction and overlap filtering.
- `features/`: peptide feature extraction.
- `modeling/`: training, tuning, and result summaries.
- `validation/`: external-validation workflows.
- `interpretation/`: SHAP and feature-stability analysis.
- `visualization/`: confusion matrices, PCA, and comparison figures.

Run scripts from the repository root so relative paths resolve consistently. See
`docs/SCRIPT_REFERENCE.md` before modifying or rerunning older scripts.
