# Raw inputs

- `TableS1PositiveProteins.fasta`: collected positive peptide sequences.
- `filtered_negatives.fasta`: filtered negative sequences.
- `final_negatives.tsv`: negative records used by feature construction.
- `proxy_peptides_model_ready.tsv`: the model-ready proxy table used by the proxy
  dataset builder. It was previously referenced through a user-specific Downloads
  path and is now stored with the project for reproducibility.
