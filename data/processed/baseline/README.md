# Baseline feature tables

These files represent training without proxy peptides.

- `pcp_aac.tsv`: 25 predictors.
- `pcp_aac_ctd.tsv`: 172 predictors.
- `pcp_aac_ctd_dpc.tsv`: 572 predictors.
- `pcp_features.csv`: earlier PCP feature export retained for history.

Predictor counts exclude the `sequence` and `label` columns.
