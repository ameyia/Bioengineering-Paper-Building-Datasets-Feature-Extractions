# Third-party software

This folder contains CD-HIT source, compiled tools, documentation, auxiliary
utilities, and example workflows. It is not project-authored analysis code.

- `cd-hit/`: bundled CD-HIT distribution previously named `Code-folder`.
- `cd-hit-auxtools/`: auxiliary C++ utilities.
- `psi-cd-hit/`: PSI-CD-HIT utilities.
- `usecases/`: third-party examples.
- `doc/`: CD-HIT documentation.

Compiled files are retained for provenance because they were already part of the
project, but a future repository-size cleanup could replace them with an
installation instruction and version pin.
